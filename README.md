# Showcase projektov - Jakub Ďurkovič

## CS2Portal-springboot
Táto webová aplikácia bola semestrálnou prácou v predmete, v **3.semestri**, zameranom na **Spring Boot Framework a Javu**. Muselo to splniť požiadavky ako využitie REST API, objektovo-relačné mapovanie, základné CRUD operace, pripojenie na Azure databázu a taktiež aj testovanie. Frontend nebol požiadavkom, ten bol vytvorený z vlastnej iniciatívy v JavaScripte.

## Notepad-cpp
Tento projekt bol semestrálnou prácou v predmete zameranom na **C++**, v **2.semestri**, kde sme museli na základe zadania vypracovať semestrálnu prácu, ktorá spĺňala nejaké základné požiadavky ako polymorfizmus alebo správne navrhnutý diagram tried.


## Database-project
Tento projekt bol úlohou v predmete,v **2.semestri** zameraný na **databáze a prácu s PostgreSQL**. Museli sme si navrhnúť schéma databáze, vytvoriť vlastné testovacie dáta a vytvoriť 25 SQL dotazov pokrývajúcich rôzne funkcie sql. V projekte je toto schéma, scripty a príklady nejakých SQL dotazov.
