# Project Showcase - Jakub Ďurkovič

## Springboot Project : CS2Portal
This web application was a semester project in the course during the **3rd semester**, focused on the **Spring Boot Framework and Java**. It had to meet requirements such as using REST API, object-relational mapping, basic CRUD operations, connecting to an Azure database, and also testing. The frontend was not a requirement; it was created on my own initiative in plain HTML,CSS and JavaScript.

## OOP C++ Project : Notepad
This project was a semester project in a course focused on **C++**, during the **2nd semester**, where we had to complete a semester project based on an assignment that met some basic requirements such as polymorphism or a properly designed class diagram.

## Relational Databases Project
This project was an assignment in a course during the **2nd semester** focused on **databases and working with PostgreSQL**. We had to design a database schema, create our own test data, and create 25 SQL queries covering various SQL functions. The project includes this schema, scripts, and examples of some SQL queries.

## Advanced SQL
This folder contains three home assignments and exam for the course related to advanced sql, which I took in **4th semester**, where we discussed **PLSQL** and **PgPLSQL**. We were taught how to work with **procedures**, **triggers**, **packages** and even **recursion**.

## PHP,MySQL + Frontend Team Project - NTU Delivery Service
During my exchange at **NTU in Singapore**, I enrolled in a course from the faculty EEE called **Web Application Design** which mainly focused on **HTML,CSS,Javascript, PHP** and **MySQL**. Our task was to create a web app for a campus canteen delivery service. This project was a teamwork, I focused mainly on PHP, MySQL and plain HTML. Other parts of the project were done by other team members.

## Blockchain Team Project in Solidity
I'm really curious about **Web3** and **Blockchain** and I got lucky enough that **NTU in Singapore** had a course called **Blockchain Technology**. Our task was to create a service working on the Ethereum blockchain using smart contracts written in **Solidity**. We created a Dutch Auction, an auction that distributes new tokens.
