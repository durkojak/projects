## CS2Portal-springboot
Táto webová aplikácia bola semestrálnou prácou v predmete zameranom na **Spring Boot Framework a Javu**. Muselo to splniť požiadavky ako využitie REST API, objektovo-relačné mapovanie, základné CRUD operace a taktiež aj testovanie. Frontend nebol požiadavkom, ten bol vytvorený z vlastnej iniciatívy v JavaScripte.
