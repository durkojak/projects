# Basics of Artificial Intelligence

This repository contains a set of small AI-focused projects created as part of the **Basics of Artificial Intelligence** course. Each project implements classic AI problems or algorithms using **C++**.

## 📁 Projects Overview

### 🔍 Labyrinth Solver
A solver for maze pathfinding problems. Implements and compares various search strategies:
- **Breadth-First Search (BFS)**
- **Depth-First Search (DFS)**
- **Random Search**
- **Greedy Search**
- **A\* Search**

The solver visualizes and outputs the path found by each algorithm.

---

### 🧱 Minecraft PDDL – Block Stacking
A planning problem formulated in **PDDL** (Planning Domain Definition Language), where an **autonomous agent** must stack **three blocks** in space to achieve a goal configuration. Solved using classical AI planning tools. The scenario simulates block stacking in a Minecraft-like environment.

---

### ♛ N-Queens Problem
Solves the classic **N-Queens problem**, placing N queens on an N×N chessboard such that no two queens threaten each other. Includes:
- Efficient backtracking-based solution
- Support for arbitrary values of N

---

### 🔢 Sudoku Solver
A **Constraint Satisfaction Problem (CSP)**-based approach to solving Sudoku puzzles. Features:
- Domain filtering
- Constraint propagation
- Backtracking

Supports solving standard 9x9 Sudoku boards with a given initial setup.

---

### 🐺 Wolf, Goat, and Cabbage Problem
A solver for the classic river crossing problem involving a farmer, a wolf, a goat, and a cabbage. The goal is to transport all safely across the river without leaving any unsafe pair behind.

Implemented as a **state-space search problem**.

---
