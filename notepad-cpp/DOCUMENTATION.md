# NotesManager 1.0

**Základne info**

Interaktívna aplikácia NotesManager 1.0 sa bude zaoberať spracovaním file systému - bude robiť s adresármi a podadresármi, taktiež bude vedieť importovať/
exportovať do rôznych formátov a poznámky sa budú dať filtrovat/sortiť.

**Ovládanie**

NotesManager 1.0 je ovládaní čisto cez terminál, podľa toho aký user input si aplikácia pýta. Pri poznámkach ako shoppinglist,
todolist alebo recept treba napísať `stop`, keď užívateľ nechce zadávať viacej údajov.
