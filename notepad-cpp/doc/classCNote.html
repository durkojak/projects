Detailed Description

Abstraktná parent trieda CNote reprezentuje poznámku. Má funkcie, ktoré majú všetky poznámky spoločné ale aj nejaké abstraktné. master_directories = posloupnost directories od root až po poznámku name = meno poznámky tags = vektor tagov date_of_creation = dátum vytvorenia poznámky log = vektor zmien danej poznámky.
